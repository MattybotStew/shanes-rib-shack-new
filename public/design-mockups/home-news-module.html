Dev notes — WordPress

  • Module placement: homepage section (currently “Latest Shack News”) — heading, prev/next arrows and dashed rule stay; the cards are re-styled to match the News landing cards.
  • Card images use the post featured image at 1900 × 1080 (object-fit: cover), same as the landing page. Include a mobile image override so editors can use a different image on phones.
  • Excerpts come from the single post’s excerpt field — same source as the landing page cards.
  • “View All News” button is optional — links to the News landing page; omit if the client prefers the module to stay carousel-only.
  • Card row can keep the existing scroll-snap carousel behavior on all breakpoints; only the card styling changes.
