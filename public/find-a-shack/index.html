Switching locations on a phone

On a computer, the red “Change Your Shack” button sits next to the logo on every page. On a phone it isn’t shown — so customers have to go Menu → Locations → search → open a shack → View Details. That’s 3–4 taps plus typing, and only if they think to look. Below are six ways to cut that down, ranked best UX first.

What a phone shows today

The shack name at the top is tappable — but it opens that shack’s page. It never lets you pick a different one.

Live top bar, 390 px
Pin + “Edgewood Location” + phone. It links to the current shack — not a switcher.

Why it’s hard

  • The red “Change Your Shack” button is hidden on phones (genuinely not rendered — not just scrolled off).
  • It’s not in the menu either. The menu’s 9 items don’t include a location switcher.
  • The location picker itself already exists and works — it just has no button on mobile to open it.
  • No map on phones — only the search box and list on /locations/.

Option 1 · Rank 1

Tap the top location → pick a shack

Make the shack name (already in the top bar) open the location picker that already exists. Show 4 nearest, one tap to switch. Adds a small chevron and underline so it reads as clickable.

Option 6 · Rank 6

Add it to the top of the menu

Make “Change Your Shack” the first item in the hamburger menu, with the current shack as a subtitle. The smallest visual change, and a safe fallback if the top bar can’t be repurposed.

2 tapsLow effortOriginal brief option 2

Why #6: low effort and safe as a fallback, but it hides behind the hamburger — the hardest to discover, and not a standalone fix.

Recommendation

Start with Option 1, then layer Option 3.

Option 1 is the highest return for the least work: the picker already exists, so we only need to point the top-bar location at it and add a chevron + underline. That alone takes switching from 3–4 taps plus typing to 2 taps.

Option 3 then catches new customers before they ever hunt for the menu, and Option 2 (the sticky bar) is the next-best value on ordering pages. Best of all: Option 1 as the everyday switcher, Option 2 on ordering pages, and Option 3 for first visits — with Option 5 as the picker they all open.
