Switching locations on a phone — clickable

The same six options from the written brief, now clickable. Tap any phone to open its picker, tap a shack to choose it, or tap Play all demos to walk through every option in turn.

What a phone shows today

The red “Change Your Shack” button is hidden on phones, and it isn’t in the menu either. Today: Menu → Locations → search → shack → View Details — 3–4 taps plus typing.

  • The picker it drives already exists and works — it just has no trigger on mobile.
  • The top-bar shack name links to the current shack, it doesn’t switch.
  • No map on phones — search controls and the card list only.

Option 6 · Rank 6

Add it to the top of the menu

Make “Change Your Shack” the first item in the hamburger menu, with the current shack as a subtitle. The smallest visual change, and a safe fallback if the top bar can’t be repurposed.

2 tapsLow effortOriginal brief option 2

Recommendation

Start with Option 1, then layer Option 3.

Option 1 is the highest return for the least work: the picker already exists, so we only need to point the top-bar location at it and add a chevron + underline. That alone takes switching from 3–4 taps plus typing to 2 taps.

Option 3 then catches new customers before they ever hunt for the menu, and Option 2 (the sticky bar) is the next-best value on ordering pages. Best of all: Option 1 as the everyday switcher, Option 2 on ordering pages, and Option 3 for first visits — with Option 5 as the picker they all open.

Clickable mockups are schematic, not final visual design. Effort labels are relative: Low = a small tweak, Medium = a few days with testing.
